# os-shutil-pathlib
Python scripts to automate file management tasks

## Description
Organizing files can be time-consuming. You have to go through the dirty work of file segregation - like, for example, which ones are photos and which ones are text files - and then moving them to separate folders.

Mind you, this isn't the problem. If you've got a gap in your schedule, you can actually do this as a way to past time.

It only becomes a problem when it prevents you from completing more important tasks on time. It is an even bigger problem if you did all the work and still end up doing it wrong like, for example, you've moved a file to the wrong folder.

So I've created this repository to help you perform these repetitive tasks with precision and with just one push of a button.

## Environment
PyCharm, or any preferred Python IDE

## Libraries
Built-in: os, shutil, and pathlib

## How to run
1. Copy and paste the codes to PyCharm or any preferred Python IDE
2. Hit the run button

## Caution
If you intend to test these scripts, please do not run them using your important files. Use disposable or backup files instead.
